# SpendWise Dashboard

## Project Description

SpendWise is a responsive financial dashboard created using HTML and CSS.

The project demonstrates modern CSS layout techniques including CSS Grid,
Flexbox, CSS custom properties, responsive design, and card micro-interactions.

The dashboard provides a visual overview of different spending categories
such as Food, Transport, Rent, Entertainment, Savings, and Utilities.

---

## Features

- Responsive dashboard layout
- Sidebar navigation menu
- Header with user information
- Six financial category cards
- CSS Grid for the dashboard layout
- Flexbox for arranging dashboard components
- CSS custom properties for the theme
- Responsive design for smaller screens
- Hover and keyboard focus effects
- Dark theme support

---

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- CSS Media Queries

---

## Dashboard Categories

The dashboard contains six categories:

1. Food
2. Transport
3. Rent
4. Entertainment
5. Savings
6. Utilities

Each category displays realistic static financial information.

---

## Responsive Design

The dashboard is responsive and adapts to different screen sizes.

On screens below 768px, the dashboard changes into a single-column
layout so that the content can be viewed comfortably on smaller devices.

---

## CSS Grid and Flexbox

CSS Grid is used for the overall dashboard structure and the category cards.

Flexbox is used for:

- Sidebar navigation
- Header content
- Dashboard cards
- Card content
- User information

---

## CSS Custom Properties

The project uses CSS variables in the `:root` selector to maintain a
consistent theme.

Examples include:

- Brand color
- Accent color
- Background color
- Surface color
- Primary text color
- Secondary text color
- Border color

---

## Micro-interactions

Dashboard cards include subtle hover and keyboard-focus effects.

The animations use:

- `transform`
- `box-shadow`
- CSS transitions

The transition duration is 200ms, which is within the required 250ms limit.
